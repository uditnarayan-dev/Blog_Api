Welcome to My Blog API

By using this API, You can manage posts, categories, and tags through these endpoints:

Posts

  • /api/posts/

You can create, retrieve, update, and delete posts via this endpoint.

Categories

  • /api/categories/

You can create, retrieve, update, and delete categories.

Tags

  • /api/tags/

You can create, retrieve, update, and delete tags.

Use these links to explore or interact with the API via your browser or a tool like Postman.

💡If authentication is enabled, you'll need a JWT token to perform write operations, But now i have disabled Authentication for showcase purpose.
